How to read this

The city’s height marks orchestration responsibility, not runtime scale. Solid arrows carry live control/data; dashed arrows are state, telemetry, or configuration feedback. Every outside-world write takes the coral adapter route.

Primary path

Input or UI request → task markdown → dispatcher → scoped Claude worker → judge / trust enforcement → a parked card, or a Tier‑2-gated publish.

Explainer: the critical seams

01Task vault is the hub. The board and workers both use markdown task artifacts in datasets/tasks; queues determine who acts.
02Workers cannot publish directly. Dispatch gives a headless, scoped Claude session task context; shipping is trusted backend code, then adapter code.
03The judge controls escalation. A score plus ladder state can revise, park for review, or auto-ship only eligible action types with global autonomy enabled.
04Cadence observes before it emits. Sentinels produce cited observations; reconciliation records drift and emits ordinary task cards, not external writes.
