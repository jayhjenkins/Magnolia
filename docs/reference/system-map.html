How to read the data flow. A verb is born (board / quick-add / meeting / cron / cadence) → lands in the task system → the dispatcher matches a worker (scoped tools + skills) → the agent runner (claude) does the work and self-reports via the task CLI → the judge/ladder/shipper trio grades, gates, and (only if allowed) ships. External writes always pass the adapter seam (Tier-2, invariant #5). Cadence observes programs, reconciles drift, and emits verbs back onto the board.
