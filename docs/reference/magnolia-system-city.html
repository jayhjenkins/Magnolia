How data moves

01Transcripts arrive at the Input Dock via Granola or Otter sync.
02The Board Server (tallest tower) creates task cards in the Task Vault (markdown + YAML on disk).
03The Dispatcher matches each task to a scoped Worker, resolves model via Profile, launches headless Claude.
04The Judge scores output; the Trust Ladder applies tier policy — park, revise, or ship.
05Only approved work reaches the Outbound Gate. Every external write is Tier-2 gated (invariant #5).
↻Cadence runs in parallel: sentinels observe, the reconciler computes drift, and proposal cards flow back into the task system.
