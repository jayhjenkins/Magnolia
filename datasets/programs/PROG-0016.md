## Intent
The portfolio-level voice. Once the operator runs two or more families of programs, this loop drafts a weekly cross-program rollup: every active program read across families, every drifting or broken program named with a reason, and the cross-program themes synthesized (two programs drifting for the same undecided decision). It dispatches the portfolio-rollup worker on a fresh cycle, gated on >=2 active families so it stays inert for a thin portfolio. The reconciler stays single-program and dumb; this is where cross-program awareness lives.
